# Bistrô Pitanga — Cardápio Digital

Primeira versão de um cardápio público, responsivo e mobile-first, com produtos fictícios e contato demonstrativo via WhatsApp.

## Requisitos

- Node.js 20.19+
- pnpm

## Desenvolvimento

```sh
pnpm install
pnpm dev
```

Para gerar a versão estática de produção:

```sh
pnpm build
pnpm preview
```

O conteúdo do restaurante, os preços, as imagens e os contatos são fictícios nesta primeira versão.
